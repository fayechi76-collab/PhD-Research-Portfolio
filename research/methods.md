# Methods and Screening Workflow

[Home](../README.md) · [Overview](overview.md) · [Evidence and Limitations](evidence.md) · [Outputs](outputs.md)

## Intended workflow

1. Define scope and reproducible database search strategies.
2. Export bibliographic records and document retrieval dates and source databases.
3. Deduplicate and screen records against explicit criteria.
4. Assign provisional mechanism labels; allow multiple labels where justified.
5. Manually audit a sampled subset, quantify disagreements, and revise labels.
6. Trace candidate mechanisms to study design, population, outcome, and causal limitations.

## Current verification boundary

Approximately 93,000 records have been described as the screening corpus, but the exact count, retrieval source, date, search query, and completed screening stages have **not been independently checked for this public portfolio**. This number must not be read as the number of full-text studies analysed.

No classification accuracy or inter-rater agreement figure is reported because no verified estimate is available.
