## Research purpose

This project explores how biological mechanisms described across neuropsychiatric disorders might overlap, differ or interact, with particular attention to inflammation, neuroendocrine regulation, metabolism and neural plasticity. It seeks to distinguish hypotheses and associations from evidence supporting causal mechanisms.

## Screening scale and disclosure

Approximately **93,000 bibliographic records** have been described as the screening corpus. The precise count, source databases, retrieval dates and completed screening stages still require verification. **This is not a claim to have read or analysed 93,000 full-text articles.**

Research questions and scientific direction are researcher-led. OpenAI-based AI tools have assisted with literature exploration, preliminary categorisation, evidence organisation, methodological discussion and technical development. Classification has not yet been systematically validated. There is no peer-reviewed publication from this work to date.

## Public/private boundary

This portfolio is an English-only public overview. The original research repository and internal handoff documents remain private. Unverified datasets, code, and interactive applications are not represented as published deliverables.
